# iOS版 Chrome

## 説明

iOS版Chromeとは、Googleが提供するWebブラウザです。ただし、iOSではAppleの制約により、ChromeであってもSafariと同じ「WebKit（ウェブページを表示する仕組み）」を使って動作します。
そのため、表示や動作の根本的な部分はSafariと共通ですが、Chrome独自のUIデザインやGoogleアカウントとの同期機能などが追加されているのが特徴です。
iOS版Chromeを使うメリットとして、ブックマーク・閲覧履歴・パスワードなどをAndroid版やPC版Chromeと同期できる点があります。これにより、どの端末でも同じようにサイト閲覧（＝ブラウジング）ができ、統一された使い心地を得られます。また、Google検索、フォーム自動入力、翻訳といったGoogleのサービスもスムーズに利用できます。
一方で、iOS版Chromeは「レンダリングエンジン（＝Webページのデータを文字・画像として画面に表示する仕組み）」がWebKitのままのため、Android版ChromeのようにGoogle独自のBlinkエンジンは使われていません。その結果、見た目はChromeでも、内部処理はSafariに近い動きになる部分もあるという特徴があります。
このようにiOS版Chromeは、Googleサービスとの連携による利便性を維持しつつ、Appleのルールに合わせて動作する形のブラウザとなっています。
